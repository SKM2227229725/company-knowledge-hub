# 🚀 KnowledgeHub AI

> An AI-powered Enterprise Knowledge Management Platform built with Django, React, and PostgreSQL.

KnowledgeHub AI is a centralized knowledge management system that helps organizations securely store, organize, search, and collaborate on internal documentation. It provides role-based access control, advanced document search, version history, and AI-powered contextual question answering using Retrieval-Augmented Generation (RAG).

---

## ✨ Features

### 🔐 Authentication & Authorization
- JWT Authentication
- Role-Based Access Control (RBAC)
- User & Department Management

### 📄 Document Management
- Create, Edit & Delete Documents
- Rich Text / Markdown Editor
- Categories & Tags
- File Attachments (PDF, DOCX, PPTX)
- Version History
- Draft & Publish Workflow

### 🔍 Smart Search
- Full-text Search
- Tag-based Search
- Department-wise Search
- Advanced Filters
- Recently Viewed Documents
- Bookmarks

### 🤖 AI Assistant
- Ask Questions from Company Documents
- AI-generated Document Summaries
- Semantic Search (RAG)
- Source References
- Suggested Related Documents

### 📊 Dashboard & Analytics
- Most Viewed Documents
- Popular Search Keywords
- Department Usage Analytics
- User Activity Logs

### 🔔 Notifications
- Document Updates
- Approval Requests
- New Knowledge Articles
